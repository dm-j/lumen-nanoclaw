# 2026-09-26

- **Central shim pool with per-group allowlist registry (host `src/modules/host-shim/registry.ts`, `exec.ts`, `mcp-manifest.ts`, `src/group-init.ts`, `src/config.ts`; instance `host-shims/_pool` + `_registry.json`, `mcp-shims/_pool` + `_registry.json`, shared `mcp-shims/lib`).** Scripts now live once in `_pool/`; `_registry.json` maps each group to the shims it may run, with per-shim env (e.g. `VAULT_PATH`). Registered groups get exactly their allowlist (an unreadable registry denies everything); groups absent from the registry keep per-group directories. Pooled shims receive `NANOCLAW_SHIM_STATE_DIR` (per-group, created on demand) and `NANOCLAW_AGENT_GROUP_ID` so shared scripts never write next to themselves. `group-init` no longer recreates private shim dirs or seeds templates for registered groups; 11 test-litter group dirs were pruned. Tests redirect via `NANOCLAW_HOST_SHIMS_DIR` / `NANOCLAW_MCP_SHIMS_DIR` so they can't touch the real trees. Docs, inventory, skills and CLAUDE.md updated. The registry covers `lumen-dmj` (host + mcp), `routine` and `dispatcher` (mcp). The vault's obsidian shims moved into the instance repo (`mcp-shims/mbif/obsidian`).
- **Shared day-token resolver (`src/day-resolve.ts`).** One resolver replaces divergent ones in `daily_note` (looked ahead) and `journal` (looked back): weekdays resolve ahead by default or back when retrospective; adds `DD` and `MM-DD`; refuses impossible dates.
- **Calendar tools (Routine).** `calendar_personal_today` renamed `get_calendar`; the hardcoded `personal` calendar parameter dropped and events labelled by their own kind; events carry an id and are addressed by a generated `lumen_file_id` plus day, with location/description readable. Notes no longer carry an `HH:MM <who>:` attribution stamp.
- **Recall/briefing shims (`host-shims/_pool/recall-host`, `briefing-host`).** `recall-host` no longer loads the vault dispatcher's `CLAUDE.md` (`CLAUDE_CODE_DISABLE_CLAUDE_MDS=1`) and uses the vault's recall agent persona instead of `seeker`; the cheap briefing model must search before answering "no relevant history"; odd space/hyphen characters in model output are mapped back so wikilink citations resolve. `docs/host-shims.md` covers the recall agent, cheap-model reliability lessons and the character normalisation.
