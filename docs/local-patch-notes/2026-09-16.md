# 2026-09-16

- Built the `routine` agent (reminders + calendar) and wired it into the a2a (agent-to-agent) delegation mesh with Dispatcher — the first real specialist agent exercising the multi-agent routing added the day before.
- Hardened agent-to-agent delegation against runaway back-and-forth: tagged sender identity on a2a messages, added loop and pair-streak breakers, and disambiguated the transcript recipient for both a2a and channel-delivered turns.
- Added `assign_task`: each delegated work order now gets its own dedicated a2a session instead of sharing one long-lived session with its coordinator. Added `acknowledge_completion`/`report_completion` MCP tools so a worker can signal task completion without triggering an ack loop; a same-day attempt to also auto-close the session on `report_completion` was reverted after realizing today's shared long-lived a2a sessions (e.g. Routine, Computation) would be prematurely closed after their very first completed task — the two tools still exist and still short-circuit ack loops, they just no longer touch session lifecycle.
- Added `--stateless` scheduled tasks: a recurring task whose work is fully self-contained per run can skip transcript resume entirely (rolled out to Routine's calendar-check task series).
- Disallowed direct `Task`/`TeamCreate` subagent dispatch from inside agents, since it bypasses the model-routing layer (PrefixRouter) — subagent work now has to go through the sanctioned delegation path.
- Minor fixes: validate that `remember`'s `extra` parameter is a JSON object, and seed default PrefixRouter `env`/`blockedHosts` for brand-new agent groups.
- Added a Computation specialist agent group (jq, python3/pip/venv, node/npm; a2a-only, no `ncl` access) for ad-hoc calculations and scripting, delegated to from Dispatcher; fixed Dispatcher to actually delegate computation work instead of doing it inline.
- Hardened two headless host-shim scripts (`recall-host`, and the write-access denylist shared with `briefing-host`): `recall-host` no longer calls Claude directly against David's personal OAuth login (routed through PrefixRouter instead, so it doesn't burn personal-subscription usage), both now surface the real exit code/output on failure instead of failing silently, and the disallowed-tools list needed `Bash` added since `Write`/`Edit`/`NotebookEdit` alone didn't stop a plain shell redirect from writing a file.
- Fixed the personal-calendar tool to actually see a recurring event's modified single occurrences, then went further and made it expand recurring series into their real occurrences via RRULE (previously only the master event's first-ever occurrence was visible). Removed Lumen's own calendar tools now that Routine owns calendar work, and added a `gaps_log` MCP tool to Dispatcher that records requests it couldn't fulfill, as signal for future specialist-agent development.
