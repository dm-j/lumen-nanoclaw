# 2026-09-23

- **Session-sync crash fix (`src/session-sync/transport.ts` and `container/agent-runner/src/session-sync/transport.ts`).** A malformed payload on a registered channel (e.g. session-sync) threw inside a handler and, via `ws.emit('message')`, killed the whole host process. Each `ws.on('message')` handler is now wrapped in try/catch: the error is logged with the session id and only the offending connection is terminated. Regression tests on both sides.
- **Session-sync investigation (docs only).** Canary retests and a clean-slate run established that the sync-transport "40s drop" was a chain-divergence resync storm rather than a Docker or network fault; findings recorded in `docs/session-sync-transport.md` and the roadmap, including a simpler log+watermark+epoch protocol direction. A session-DB sprawl investigation was added to the top of the roadmap. The transport is still not the live path.
- **Worktree hook hardening (`.husky/post-checkout`).** Now also calls `~/.claude/hooks/worktree-registry.sh sync` so every worktree lands in the global registry, and runs the install under an explicit PATH (node@22, `/opt/homebrew/bin`) because Claude Code spawns hooks with a minimal PATH in which `pnpm` was not found.
- **Fresh-install backup/restore.** Added `scripts/lumen-backup.sh`, `scripts/lumen-restore.sh`, `docs/fresh-install.md` and a move checklist for rebuilding Lumen on a wiped machine, plus a `fresh-install-gaps` roadmap item.
- **Notes system (Routine and Lumen).** Instance repo: new `routine/notes` mcp-shims (add/edit/delete/read plus a notes-block builder) and matching `lumen-dmj/notes` host shims, so a day's ID'd notes block is injected into the wake script (capped, with rollback). Day arguments match by unique prefix; `notes_delete` only suffixes the note ID with `-deleted` (no strikethrough, which is reserved); agents are told in the wake script to delete finished notes; a nightly notes carry-over task was added for Lumen. Calendar event notes gained an event-body helper and kind labels; `scripts/calendar-note-body-backfill.mjs` backfilled existing event notes (drop the When line, screen Teams signatures, `^event-desc` quote block). A calendar `day_index` (with selftest) was added. Documented as new `notes_*` shims in the inventory.
- Many roadmap/design items recorded (modular context-injection assembler spec, Teams-signature screening spec, calendar day_index links, vault sync hand-off briefs, ics-handling refresh); no code.
