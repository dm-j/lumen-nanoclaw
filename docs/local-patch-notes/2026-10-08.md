# 2026-10-08

- **Host log timestamps are ISO-8601 UTC with date (`src/log.ts`)** instead of bare local `HH:MM:SS.mmm`, so multi-day logs can be windowed and correlated with DB timestamps.
- **Projected sessions: prompt-size reductions (container `projected-sessions.ts`, `poll-loop.ts`, `formatter.ts`; host `synthesize.ts`, `container-runner.ts`).** A projected container now sends `x-session-id` (the projected session key) on inference via `ANTHROPIC_CUSTOM_HEADERS` so PrefixRouter's `/cache-status` can report live/expired; the warm-query reset consults it on each follow-up (resetting on follow-up count, expired cache, or idle time only when status is unknown) instead of a fixed 5-minute TTL. Follow-up count and responder tail are 12 (were 30 and 15). The `<briefing>`/`<recent-turns>` header is sent once per query; follow-ups carry the briefing only if changed and only unseen tail turn blocks (diffed by turn block, briefing entries skipped), and omit the `<context timezone>` tag. The responder keeps 2 past briefings (was 5).
- **Fewer built-in tool definitions per request (`container/agent-runner/src/providers/claude.ts`).** Denied Workflow, Monitor, the Task* tools, PushNotification and NotebookEdit (~40 KB of tool definitions, 54% of Lumen's cold prompt was tools). The `task_management` mcp-shims were disabled for Lumen (instance registry/lines removed, wrappers renamed `-host-disabled`).
- **`x-agent-group` header** is sent on every container's inference calls (`src/container-runner.ts`).
