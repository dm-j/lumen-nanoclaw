# 2026-09-22

- **Runaway a2a guard loop fixed (host, `src/modules/agent-to-agent/agent-route.ts`).** A broken `container.json` (stale `ANTHROPIC_BASE_URL` in the `_ping-test` group, also corrected in the instance repo) made every model call fail; the repeat-loop and pair-message-limit guards each woke the container they had just throttled, which re-tripped them, producing ~90 minutes of runaway spawns, host heap exhaustion and a crash-looping service. `blockDelivery` now writes its "stop and escalate" notice and wakes the target only on the first trip of an unbroken streak; further trips for the same streak write the notice silently. The streak re-arms when any other message lands in the target's inbox. Regression tests added.
- **Worktree auto-provisioning (`.husky/post-checkout`, tracked `.husky/_/post-checkout` and `.husky/_/h`).** A fresh `git worktree add` now gets its `groups/`, `mcp-shims/`, `host-shims/` instance symlinks and a Node-22 `pnpm install` automatically (only inside a worktree), so the first commit's prettier pre-commit hook works. The two husky dispatcher stubs are now tracked, otherwise `core.hooksPath` pointed at an empty directory in a new worktree.
- **Routine's calendar becomes vault-backed (instance `mcp-shims/routine/calendar/`).** Added calendar add/edit shims, replaced `ics-events` with a vault-based `range-events`, and added a calendar conflict-scan, `note_append` and `personal_delete`. A calendar conflict-detection design was written up, wired to a live trigger (a routine conflict-check task) and the roadmap item closed; the routine-vault-calendar roadmap item was closed too.
- Silenced a false-positive "no JSON-parsing call" warning that the host's static shim scanner printed at every container spawn for `-host` wrappers that hand `$1` to a sibling script (a comment naming `JSON.parse` satisfies it).
